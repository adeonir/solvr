# Intent: Use sheets through URLs

## Problem

The author wants to open and change sheets through a URL scheme. The calling workflows are not stated.

## Proposed outcome

Users can open a sheet, create a sheet with given text, and append given text to a sheet through a URL scheme.

## Affected users and systems

The author and other Mac users with the same use cases; sheets and applications that open URLs.

## Constraints

- The URL scheme supports opening, creation with text, and appending text.

## Open questions

None.
