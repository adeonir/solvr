# Intent: Install the app and stay updated

## Problem

Other Mac users with the same use cases need a way to obtain the app. The author wants automatic app updates.

## Proposed outcome

Users can install the app by direct download or Homebrew and receive automatic app updates. App Store distribution is also planned, subject to confirmation.

## Affected users and systems

The author and other Mac users with the same use cases; macOS, direct download, Homebrew, and the planned App Store distribution.

## Constraints

- The app runs on macOS 26 or later.
- Distribution includes direct download and Homebrew. App Store distribution is planned, subject to confirmation.
- The app updates itself automatically for every distribution method.

## Open questions

Will the planned App Store distribution be confirmed?
