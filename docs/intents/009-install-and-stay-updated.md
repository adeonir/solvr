# Intent: Install the app and stay updated

## Problem

Other Mac users with the same use cases need a way to obtain the app. The author wants automatic app updates.

## Proposed outcome

Users can install the app by direct download or Homebrew and receive automatic app updates.

## Affected users and systems

The author and other Mac users with the same use cases; macOS, direct download, and Homebrew.

## Constraints

- The app runs on macOS 26 or later.
- Distribution is direct download and Homebrew.

## Open questions

None.
