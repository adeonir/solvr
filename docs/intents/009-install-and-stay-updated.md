# Intent: Install Nume and stay updated

## Problem

Other Mac users with the same use cases need a way to obtain Nume. The author wants automatic app updates.

## Proposed outcome

Users can install Nume by direct download or Homebrew and receive automatic app updates. App Store distribution is also planned, subject to confirmation.

## Affected users and systems

The author and other Mac users with the same use cases; Nume, macOS, direct download, Homebrew, and the planned App Store distribution.

## Constraints

- Nume runs on macOS 15 or later.
- Distribution includes direct download and Homebrew. App Store distribution is planned, subject to confirmation.
- Nume updates itself automatically for every distribution method.

## Open questions

Will the planned App Store distribution be confirmed?
