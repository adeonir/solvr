# Intent: Access Nume during work

## Problem

The author uses a text calculator for quick calculations during work and wants control over how Nume is opened and accessed.

## Proposed outcome

Users can access Nume through the Dock or menu bar, open it from any app with a global hotkey, and have it open at login.

## Affected users and systems

The author and other Mac users with the same use cases; Nume, the macOS Dock, menu bar, global hotkeys, and login.

## Constraints

- Nume appears either in the Dock or in the menu bar. Show in Menu Bar is off by default.
- Enabling Show in Menu Bar moves Nume from the Dock to the menu bar; disabling it moves Nume back.
- The menu bar icon menu opens the window, opens Settings, and quits Nume.
- A global hotkey opens Nume from any app. Launch at Login opens Nume when the user logs in to macOS.
- Users configure the global hotkey in Settings. No global hotkey is configured by default.
