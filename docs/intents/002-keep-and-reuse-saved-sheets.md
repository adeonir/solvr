# Intent: Keep and reuse saved sheets

## Problem

The calculators the author uses do not keep sheets between sessions. The author needs recurring calculations such as budgets and expense splits. The evidence comes from personal daily use.

## Proposed outcome

Users can create named sheets, return to automatically saved changes between sessions, rename sheets, duplicate sheets, and delete sheets they no longer need.

## Affected users and systems

The author and other Mac users with the same use cases; Nume sheets.

## Constraints

- Each sheet has a title that can be renamed.
- Nume saves each sheet automatically after each change, with no save action.
- Only the first sheet deletion asks for confirmation.

## Open questions

None.
