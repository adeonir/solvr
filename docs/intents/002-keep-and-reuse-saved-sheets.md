# Intent: Keep and reuse saved sheets

## Problem

The calculators the author uses do not keep sheets between sessions. The author needs recurring calculations such as budgets and expense splits. The evidence comes from personal daily use.

## Proposed outcome

Users can create sheets, return to automatically saved changes between sessions, rename sheets, duplicate sheets, and delete sheets they no longer need.

## Affected users and systems

The author and other Mac users with the same use cases; sheets.

## Constraints

- Each sheet has a title that can be renamed.
- Changes are saved automatically after each edit, with no save action.
- The list of sheets shows the most recently edited sheet first.
- Only the first sheet deletion asks for confirmation.

None.
