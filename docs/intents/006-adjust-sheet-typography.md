# Intent: Adjust sheet typography

## Problem

The author wants control over the sheet font family, size, and line height. A specific readability problem is not stated.

## Proposed outcome

Users can choose an installed monospaced font and adjust its size and line height.

## Affected users and systems

The author and other Mac users with the same use cases; Nume sheets and fonts installed on the Mac.

## Constraints

- The font family can be any installed monospaced font.
- Size is in px and defaults to 13. Line height defaults to 2.
- An empty size or line height field restores its default.

## Open questions

None.
